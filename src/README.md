# Himanshu Mishra — Portfolio

A Linux-inspired personal portfolio built with React and Vite. It highlights my projects, cloud and SAP credentials, Linux learning, and involvement with GeeksforGeeks RBU On Campus.

## Run locally

From the repository root:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Project layout

- `index.html` — Vite HTML entry point
- `src/main.jsx` — React portfolio
- `src/style.css` — responsive terminal-inspired theme
- `public/` — profile photo, certificates, and credential artwork

Python and Coursera certificates are intentionally not included in the portfolio.
